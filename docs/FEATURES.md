# Delta Force Operator Toolkit — feature reference

Operator notes, loadout groups, and control reference form the core of Delta Force Operator Toolkit. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Operator notes | Character or team groups presented with the context needed to organize a session. |
| Loadout groups | Equipment categories and the associated selection or configuration options. |
| Control reference | A dedicated section for control reference and the configuration details associated with that area. |

The project page follows the same section structure.
